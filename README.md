# Sitio web de OANIG

Página oficial del juego OANIG (Godot 4) y su política de privacidad.

- `index.html` — landing del juego (imágenes embebidas, sin dependencias)
- `privacidad.html` — política de privacidad (requerida por Google Play)
- `vercel.json` — configuración de despliegue (URLs limpias)

Desplegado en Vercel.
